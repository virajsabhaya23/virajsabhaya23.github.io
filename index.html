Open source | Reliability

EffectFence

A Python crash/retry and MCP side-effect conformance verifier. Explores modeled failure schedules and checks observed effects for duplication, loss, and stale retries.

Includes a 30-case deterministic benchmark and a separate live Kafka/PostgreSQL crash test between sink commit and offset commit. Reports include traces and content-addressed evidence; results are bounded by the tested schedules and configured observers.

Open source | Supply-chain security

SBOM Evidence Fusion

A Python tool that reconciles CycloneDX/SPDX documents and package-manager dependency evidence while preserving source provenance and uncertainty.

Reports dependency-graph reachability as reachable, unreachable, or unknown, with a 100-case synthetic benchmark. The analysis concerns dependency relationships, not code-level exploitability; real-world comparative validation remains future work.
